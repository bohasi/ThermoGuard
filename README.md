# 🌡️ ThermoGuard

ThermoGuard is a lightweight, Python-based Terminal User Interface (TUI) tool designed to monitor PC performance and hardware health in Linux/Unix environments.

## 🚀 Features
* **Real-time Monitoring:** Track CPU usage, memory consumption, and disk activity.
* **Temperature Tracking:** Keep an eye on your system's thermal status to prevent overheating.
* **Lightweight:** Designed to run with minimal overhead, making it ideal for servers and low-resource machines.
* **Clean TUI:** Simple and intuitive text-based interface.
